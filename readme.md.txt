# DAR Pangasinan Website

Official-style website concept for the Department of Agrarian Reform
Pangasinan Provincial Office.

## Features

- Responsive government website design
- DAR Pangasinan homepage
- About section
- Divisions and functions
- DAR programs
- Public services
- News and announcements
- Transparency section
- FAQ
- Contact form
- Dark mode
- Mobile navigation
- Animated statistics
- Division information modal
- GitHub Pages compatible
- No backend required

## Project Structure

dar-pangasinan/

├── index.html
├── style.css
├── script.js
├── README.md
└── assets/

    ├── logo.png
    └── hero.jpg

## How to Run Locally

1. Download or clone the repository.

2. Open the project folder.

3. Double-click:

index.html

The website will open in your browser.

## GitHub Pages

1. Create a new GitHub repository.

2. Example repository name:

dar-pangasinan

3. Upload:

index.html
style.css
script.js
README.md

4. Create an assets folder.

5. Upload your official images into assets.

6. Go to:

Repository
→ Settings
→ Pages

7. Under "Build and deployment":

Source:
Deploy from a branch

Branch:
main

Folder:
/

8. Click Save.

GitHub will generate the website URL.

Example:

https://YOUR-USERNAME.github.io/dar-pangasinan/

## Important

Before publishing the website as an official government website,
replace placeholder contact information, statistics, personnel,
news, documents, and images with verified information from the
Department of Agrarian Reform Pangasinan.

## Image Files

The homepage expects:

assets/hero.jpg

If the image does not exist, the hero section will still display
the green background.

## Contact Form

The contact form is currently front-end only.

For actual email submission, connect it to:

- an official government email system
- a backend application
- Formspree
- EmailJS
- Google Apps Script
- or another approved government-compatible service

Do not collect sensitive personal information without appropriate
security, privacy, and authorization controls.
